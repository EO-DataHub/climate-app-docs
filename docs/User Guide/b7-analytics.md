# Analytics

![Analytics](/climate-app-docs/images/navigation/analytics.png "Analytics"){ align=right }
The [Analytics page][Analytics] is accessed from the left hand navigation bar:

## Overview

The [Analytics page][analytics] displays the results of any workflows that you have executed on your asset portfolio.  *Workflow analysis* can be called from the *hazards*, *observations*, and *assets* pages once an asset dataset has been uploaded or opened from an existing portfolio.

## Outputs

The outputs on the Activity screen will depend on the workflow that has been executed.

All workflows include an **Asset list** table that includes a paginated view of all the assets with columns for the workflow results.  The example below shows the ouput from a *Land Surface Temperature* worfklow.
![Analytics](/climate-app-docs/images/analytics/1a.png "Analytics")

Select **View Details** from the table to explore in detail the results for each individual asset.
![Analytics](/climate-app-docs/images/analytics/2a.png "Analytics")

On the left hand panel the **Visualisation** option displays a graph of the data outputs.
![Analytics](/climate-app-docs/images/analytics/3a.png "Analytics")
