# Portfolios

![Portfolios](/climate-app-docs/images/navigation/portfolios.png "Portfolios"){ align=right }
The [Portfolios page][portfolios] is accessed from the left hand navigation bar:

## Overview

A [Portfolio][portfolios] is an asset dataset that has been uploaded to your own personal storage area on the hub and is stored persistently.  *Portfolios* will therefore be available to you next time you log in, thereby saving the inconvenience of needing to upload your assets each time.  The [Portfolios page][portfolios] provides you with some tools to manage these portfolio datasets (for example deleting those that are no longer needed).

## Portfolios

To access the **portfolios** tools, it is necessary to **login** first.  Further details are available on the [login] page.  Use the **New portfolio** button to upload a new asset dataset.  This will be validated on upload and displayed in the portfolio view.  

![Portfolios](/climate-app-docs/images/portfolios/1.png "Portfolios")

## File formats

The support formats for portfolios are **CSV** and **GeoJSON**.  The format of **CSV** files requires an **ID**, **Latitude** and **Longitude** as further detailed in the [assets] page.   **CSV** files work well for point datasets.  For asset datasets that are **lines** or **polygons**, data needs to be uploaded in **GeoJSON** format.  Guidance on this will be provided in a further release of this documentation.
