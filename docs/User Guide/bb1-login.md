# Login and User Accounts

![Login](/climate-app-docs/images/navigation/login.png "Login"){ align=right }
The [Login page][Login] is accessed from the left hand navigation bar:

## Overview

The [Login page][login] page allows you to log in and out of your EODH account.  Some features of the application are avaialble without login - for example viewing the hazard indicator and observations data.
 Other features, such as uploading your own asset data and running asset analysis workflow require an EODH login.

## User Accounts

You can login to the application using either an EO Data Hub login, or using GitHub.

### EO Data Hub username

If you have been set up with a user account on the hub, then you can login with your hub username and password.  In general hub user accounts are for system accounts only (such as those available to development partners).

### GitHub sign in

You can also login to the application using a GitHub account.  However, for all of the features to work, you will need to have a _workspace_ created for you on the Hub.  Please follow the link below to email to the team, replacing the relevant parts of the email with your own details.

[Email enquiries@eodatahub.org.uk](mailto:enquiries@eodatahub.org.uk?subject=Request%20for%20workspace&body=Dear%20EODH%2C%0D%0A%0D%0APlease%20could%20you%20set%20up%20a%20workspace%20for%20the%20following%20GitHub%20username%3A%0D%0A%0D%0A%3CYOUR%20GITHUB%20USERNAME%3E%0D%0A%0D%0ARegards%2C%0D%0A%0D%0A%3CYour%20name%3E%0D%0A)

!!! note
    Please note, that it may take up to two working days for your workspace to be set up.  You will be emailed confirmation once this has been done.

## Logging in

To log in to the application, select the _Login_ (person) icon at the bottom of the navigation bar.
![Login](/climate-app-docs/images/login/1.png "Login")

If you have an EO Data Hub account, fill out the username and password with your credentials.  Alternatively if you are using a GitHub account, click on the icon beneath **Or sign in with** and enter your GitHub details.

  ![Login](/climate-app-docs/images/login/2.png){ width="400" }

## Logging out

You can log out of the system by returning to the icon in the navigation bar and selecting _Log out_.
![Login](/climate-app-docs/images/login/3.png "Login")
