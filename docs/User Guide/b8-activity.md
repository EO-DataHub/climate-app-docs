# Activity
![Activity](/uk_eodatahub/images/navigation/activity.png "Activity"){ align=right }
The [Activity page][Activity] is accessed from the left hand navigation bar:
## Overview
The [Activity page][activity] page lists all the worklows that have been executed on your asset portfolios including the history of whether they were successful or had any errors.  For historic workflows, you are able to load up the results of the previous analysis, which will then be displayed in the [Analytics page][analytics].  The time indicated in the _Activity_ view indicates the time when the workflow execution completed.
